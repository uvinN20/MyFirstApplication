# MyFirstApplication 📱

A native Android application built using **Java** and **Android Studio**.

## 📖 About the Project

This project serves as my first native Android application, developed to learn Android app architecture, XML layouts, and Java programming for mobile development.

## 🛠️ Tech Stack

- **Language:** Java
- **UI Framework:** Android XML Layouts / AndroidX
- **IDE:** Android Studio
- **Build Tool:** Gradle

## 🚀 Getting Started

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/uvinN20/MyFirstApplication.git
   ```

2. **Open in Android Studio:**
   - Open Android Studio.
   - Click on **File** > **Open** and select the cloned directory.

3. **Run the App:**
   - Connect your Android device or start an Android Virtual Device (AVD).
   - Press `Shift + F10` or click the **Run** button in Android Studio.
